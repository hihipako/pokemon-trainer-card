# 포켓몬 트레이너 카드

트레이너 일러스트 위에 포켓몬 엔트리 6마리를 얹어 카드를 만드는 도구입니다.
HTML 파일 하나 + 스프라이트시트 두 장으로 돌아가고, 서버도 빌드도 필요 없습니다.

`index.html` 을 브라우저로 열면 바로 씁니다.

---

## 할 수 있는 것

**카드 구성**

- 이름 · 신분 / 한 줄 대사 / 설명 — 넣고 싶은 것만 켜서 씁니다
- 신분은 **트레이너 칭호 215종** 목록에서 고르거나 직접 씁니다 —
  1~9세대 트레이너군 186종에 타입 전문가 18종(`고스트 트레이너`)과
  지방 챔피언·직책 11종(`가라르 챔피언`)을 더한 것
- 트레이너 이미지를 올리면 자르기 화면이 열립니다. 카드의 사진 칸과 같은 비율로 잘리며,
  끌어서 위치를 잡고 슬라이더로 크기를 정합니다. 카드 위에서는 움직이지 않습니다
- 스티커 · 로고 이미지를 여러 장 얹어 **카드 어디로든** 옮기고 크기를 바꿉니다
- 배경색은 하양 · 검정 원터치, 또는 원하는 색 아무거나. 글자색은 배경 밝기에 맞춰 뒤집힙니다

**엔트리 6마리**

- 사진 위에는 도트 스프라이트만 얹히고, 칸을 누르면 그 자리 편집창이 열립니다
- 왼쪽 막대에 `닉네임 / 포켓몬 종류 / 성별 / 사이즈 / 리본` 순으로 정리됩니다 (안 적은 항목은 건너뜀)
- 포켓몬 **1530종** — 기본 1025종에 폼 505종. 알로라 · 가라르 · 히스이 · 팔데아 · 메가 · 거다이맥스는
  물론, 트리토돈 동쪽바다 · 플라제스 꽃 색깔 · 비비용 무늬 20종 · 안농 28자 · 마휘핑 64종처럼
  능력은 같고 모습만 다른 폼까지 들어 있습니다
- 이름 · 영문명 · 도감번호로 검색하고, **초성 검색**도 됩니다 (`ㄴㅍㅇ` → 님피아)
- 사이즈 XS · S · M · L · XL, 성별, 이로치
- **증표 98종**의 칭호와 **리본 101종**을 목록에서 고릅니다

**저장**

- 카드를 PNG로 내보냅니다 (편집용 표시는 빠지고 완성본만 담김)
- 글 · 색 · 엔트리 · 배치는 자동 저장되고, 카드 코드로 다른 사람에게 넘길 수 있습니다

## 직접 빌드하기

데이터와 스프라이트시트는 이미 들어 있어서 그냥 써도 됩니다.
포켓몬이 추가되는 등 새로 만들고 싶을 때만 필요합니다.

```bash
npm install
npm run build          # 데이터 → 스프라이트 → 시트 → index.html
```

| 명령 | 하는 일 |
| --- | --- |
| `npm run build` | 전체 빌드 |
| `npm run build:data` | `data/payload.json` 과 `index.html` 만 |
| `npm run build:sheets` | 스프라이트를 내려받아 시트 두 장만 |
| `npm run build:html` | `src/template.html` + `data/payload.json` → `index.html` |
| `npm start` | `http://localhost:8080` 으로 띄우기 |
| `npm test` | 가상 브라우저로 화면을 실제로 눌러보는 점검 (60항목) |

내려받은 원본(CSV · 위키 문서 · 스프라이트 3060장)은 `.cache/` 에 쌓이고 재실행 때 재사용됩니다.
전체 빌드는 처음 한 번만 네트워크를 쓰며 1~2분쯤 걸립니다.

## 구조

```
index.html            바로 열 수 있는 완성본 (데이터가 안에 박혀 있음)
sheet-normal.webp     도트 스프라이트시트 — 일반  3072×4608, 무손실
sheet-shiny.webp      도트 스프라이트시트 — 이로치
src/template.html     데이터가 빠진 원본. 화면을 고칠 때는 이 파일을 고칩니다
data/payload.json     포켓몬 1530종 · 증표 · 리본 · 트레이너 칭호 데이터
tools/build.js        빌드 스크립트
tools/serve.js        의존성 없는 정적 서버
tools/smoke.js        가상 브라우저로 화면을 눌러보는 점검
```

`src/template.html` 을 고쳤다면 `npm run build:html` 로 `index.html` 을 다시 만들어야 반영됩니다.

### 스프라이트시트에 대해

스프라이트 3060장을 96px 칸으로 잘라 32열짜리 한 장에 담고, CSS `background-position` 으로 꺼내 씁니다.
무손실 WebP로 **한 장당 약 1MB** 입니다 — 같은 내용을 PNG로 두면 6MB가 넘고, 낱장으로 두면
요청이 3060번 나갑니다. 원본과 픽셀이 완전히 같은지 빌드할 때 검증합니다.

## 데이터 출처

- 포켓몬 도트 스프라이트 · 한글 이름 · 타입 · 성별비 — [PokéAPI](https://pokeapi.co/)
  ([sprites](https://github.com/PokeAPI/sprites), [pokeapi](https://github.com/PokeAPI/pokeapi))
- 증표(칭호) 98종 · 리본 101종 · 트레이너군 170종 — [포켓몬 위키](https://pokemon.fandom.com/ko/wiki/증표)
  - 트레이너군 문서는 7세대까지만 실려 있어 8·9세대는 `tools/build.js` 에 적어 두었습니다
  - 문서가 옛 이름으로 적어 둔 것(`중` → `수행자`, `기도사` → `주술사` 등)은
    `TRAINER_RENAME` 에서 게임의 한국 명칭으로 바로잡습니다
  - 조직 이름(`로켓단`)과 특정 인물만의 직책(`타워타이쿤`, `캐슬버틀러`)은
    트레이너군이 아니라 `TRAINER_DROP` 과 인물 문서 링크 판별로 걸러 냅니다

한글 폼 이름이 원본에 없는 경우(히스이 · 팔데아 · 거다이맥스 등)는
`tools/build.js` 의 `FORM_KO` 표에서 채웁니다. 마휘핑은 크림 이름과 사탕 아이템
이름(`item_names.csv`)을 합쳐 `밀키루비 · 베리사탕` 처럼 만들고, 아르세우스는
타입 이름을 씁니다. 지금은 영문으로 남는 폼이 없습니다.

분이벌레 · 분떠도리 · 나메일의 무늬 폼은 도트가 기본형과 똑같아 넣지 않습니다.
